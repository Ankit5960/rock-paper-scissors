# Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer and see who wins!

## 🎮 About the Project

This project is created to practise JavaScript fundamentals, DOM manipulation, event handling, and conditional logic.

## ✨ Features

- Three choices: Rock, Paper, and Scissors.
- Computer generates a random choice.
- Automatically determines the winner.
- Displays win, lose, and draw messages.
- Tracks player and computer scores.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start playing!
